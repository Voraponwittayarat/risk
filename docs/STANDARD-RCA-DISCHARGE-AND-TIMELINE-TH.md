# จำหน่ายจาก Standard RCA และวาง Timeline จาก Excel

## การจำหน่ายเมื่อไม่ต้องทำ RCA

ปุ่ม `ทบทวนแล้วไม่ต้องทำ RCA/จำหน่ายเคส` เปิดช่องระบุเหตุผลก่อนยืนยันปิดอุบัติการณ์ ใช้ได้เฉพาะหัวหน้าหน่วยงาน/กรรมการความเสี่ยง/ผู้ดูแลที่มีสิทธิ์สรุป RCA ในขอบเขตนั้น ต้องมีเหตุผล 10–2000 ตัวอักษรและ version ตรงกับข้อมูลปัจจุบัน

ระบบเก็บร่าง RCA เป็น CANCELLED, ปิดอุบัติการณ์เป็นจำหน่าย, ยุติคิวทีม/SLA, เพิ่มผลการทบทวนและ workflow audit ไม่ลบประวัติและไม่สร้าง Risk Register หรืออ้างว่า RCA สำเร็จ หากมี CAPA หรือ RCA อื่นที่ยังดำเนินการ ระบบปฏิเสธการปิดข้ามขั้นตอน

## Timeline

ใส่วันที่ด้วยตัวเลือกปฏิทิน เวลาใช้ข้อความได้ (เช่น ก่อนเกิดเหตุ) และรายละเอียดหลายบรรทัดได้

คัดลอกเซลล์จาก Excel ตามลำดับ `วันที่ | เวลา | เหตุการณ์ | จุดวิกฤต` โดยคอลัมน์สุดท้ายไม่บังคับ วางในช่องนำเข้าแล้วกดตรวจ/ดูตัวอย่างก่อนกดเพิ่ม ระบบเพิ่มต่อรายการเดิม ไม่ทับข้อมูลที่กรอกไว้

รองรับหัวตาราง, วันที่ YYYY-MM-DD หรือ d/m/YYYY (พ.ศ./ค.ศ. ปี4หลัก), วันที่ว่าง, เซลล์หลายบรรทัดและเครื่องหมายคำพูดแบบ Excel; ปฏิเสธวันที่ผิด/คอลัมน์ผิดและจำกัด200แถวต่อครั้ง จุดวิกฤตใช้ใช่/ไม่,1/0,true/false,yes/no

ใช้ schema event_date เดิม ไม่ต้องเพิ่ม migration และยังไม่ดำเนินการกับข้อมูล production ตาราง legacy MyISAM มีข้อจำกัดเรื่อง transaction จึงต้องสำรองและตรวจผลหากนำขึ้นจริงตาม runbook

ตรวจ frontend/backend build ผ่าน, backend RCA 21 tests ผ่าน และ parser Excel 3 tests ผ่าน ตรวจ git diff แล้ว ยังไม่ได้ทดสอบหน้าจอใน browser หรือ deploy; ก่อน release ให้ตรวจด้วยข้อมูลทดสอบกรณีวางตาราง/บันทึก/เปิดซ้ำ และจำหน่ายพร้อมตรวจผลการทบทวนและ audit
