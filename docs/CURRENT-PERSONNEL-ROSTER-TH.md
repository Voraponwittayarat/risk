# นำเข้ารายชื่อเจ้าหน้าที่ปัจจุบัน

เข้าด้วย Admin แล้วเปิด **ระบบ & กำหนดสิทธิ์ → จัดการข้อมูลบุคลากร → นำเข้ารายชื่อ / เทียบของเดิม**

1. เลือก CSV UTF-8 ที่มีรายชื่อปัจจุบันครบทั้งโรงพยาบาล รองรับ 1–3,000 คน / 5 MB ไม่ต้องปรับไฟล์แบบที่ส่งมา ระบบอ่านหัวตารางหลังบรรทัดชื่อเอกสารและข้ามตารางสรุปด้านข้าง
2. ตรวจสถานะ มีแล้วในชุดก่อน / ข้อมูลเปลี่ยน / พบในทะเบียนเดิม / ใหม่ ตารางแสดงชื่อ ตำแหน่ง งาน ประเภทการจ้างและค่าเดิมให้เทียบ ค้นหาหรือกรองเฉพาะคนที่ยังไม่เชื่อมได้
3. จับคู่ **กลุ่มงาน + งานใน CSV** กับหน่วยงานในระบบ ใช้ค่าที่ตรงกับชื่อหน่วยงานเพียงรายการเดียว หรือการจับคู่จากชุดก่อน ถ้าระบบหาไม่ได้ให้เลือกเอง การเลือกครั้งเดียวใช้กับทุกคนในงานนั้น
4. ตรวจการเชื่อมกับทะเบียนบุคลากรเดิม ชื่อที่ตรงกันเพียงคนเดียวหลังตัดคำนำหน้าและช่องว่างจะเสนอให้เลือก ชื่อคล้ายกันไม่จับคู่โดยประมาณ ชื่อซ้ำในทะเบียนต้องเลือกคนที่ถูกต้องเอง
5. คนที่ยังไม่มีทะเบียนเลือก **ยังไม่มีทะเบียน / ไม่เชื่อม** ได้และยังนับในยอดเจ้าหน้าที่ หากต้องการนับรายงานของคนนั้น ให้นำเข้าไฟล์เดิมอีกครั้งหลังสร้างทะเบียน/บัญชี แล้วเชื่อมบุคลากรให้ถูกคน ระบบนี้ไม่สร้างบัญชีหรือเปลี่ยนสิทธิ์การใช้งาน
6. ตรวจรายชื่อจากชุดก่อนที่ไม่พบในไฟล์ใหม่ คนเหล่านี้จะไม่อยู่ฐานยอดปัจจุบัน แต่บัญชีและประวัติรายงานจะไม่ถูกลบ ไม่ต้องใช้การลบบุคลากรเพื่อปรับยอดรายงาน
7. กรอกวันที่ข้อมูล **ณ วันที่** (เช่น 2 ตุลาคม 2569 ตามไฟล์ที่ส่งมา) ยืนยันว่าไฟล์ครบทั้งโรงพยาบาล แล้วกด **ยืนยันใช้รายชื่อชุดนี้** ครั้งเดียว
8. เปิดหน้าสถิติ `/reporting-stats` ใหม่ รายงานจำนวนเจ้าหน้าที่ที่รายงานแต่ละเดือนจะแสดงวันที่ฐานรายชื่อและจำนวนคนที่ยังไม่มีบัญชีเชื่อมโยง

## ความหมายของยอดในรายงาน

- ยอดเจ้าหน้าที่ใช้ทุกคนใน snapshot ที่นำเข้าล่าสุด รวมคนที่ยังไม่ลงทะเบียนและคนที่เชื่อมทะเบียนเดิมแล้ว
- ยอดผู้รายงานนับหนึ่งคนต่อเดือนจากบุคลากรในรายชื่อชุดล่าสุดที่มีบัญชีเชื่อมผ่านทะเบียนเดิม ใช้หน่วยงานที่เลือกใน snapshot ไม่ใช้หน่วยงานเก่าในบัญชี คนที่ไม่อยู่รายชื่อชุดนี้ไม่นับเป็นผู้รายงานปัจจุบัน
- เดือนและปีที่เลือกยังกรองเหตุการณ์ตามวันที่เดิม แต่ฐานบุคลากรของทุกเดือนใช้ **รายชื่อปัจจุบัน** ไม่ใช่จำนวนบุคลากรย้อนหลังในแต่ละเดือน ประวัติเหตุการณ์ไม่ได้เปลี่ยน
- ถ้ายังไม่เคยนำเข้า snapshot ระบบใช้ทะเบียนบุคลากรสถานะเปิดใช้งานแบบเดิม
- การจับคู่กลุ่มงานเป็น 17 หน่วยงานในรายงานยังใช้กติกาจัดกลุ่มหน่วยงานเดิมของระบบ

## การตรวจและติดตั้ง

เพิ่มตาราง `personnel_roster_batch` และ `personnel_roster_entry` ผ่าน migration `20261005100000_current_personnel_roster` เก็บ snapshot และข้อมูลการนำเข้าอย่างถาวรแบบเพิ่มชุดใหม่ ไม่แก้ user, member หรือ riskregister

Preview เป็นข้อมูลชั่วคราวเฉพาะเจ้าของ Admin อายุ 30 นาที ยืนยันทุกแถวใน transaction เดียว ปฏิเสธ token เก่า ชื่อซ้ำ การเชื่อมคนเดิมซ้ำ หน่วยงานไม่ครบ หรือทะเบียนเปลี่ยนระหว่างตรวจ

ก่อน production ต้องสำรองและตรวจ SHA-256 แล้วให้ updater ใช้ `prisma migrate deploy` ตามคู่มือ Ubuntu ห้าม `prisma db push` ใน production ไฟล์รายชื่อจริงไม่อยู่ใน Git ทดสอบด้วยข้อมูลจำลองเท่านั้น
