# กระดิ่งแจ้งเตือนงานของฉัน

วางกระดิ่งที่หัวเว็บข้างเมนูบัญชี แบ่งรายการส่งร่วมทบทวน งาน RCA กำหนดติดตามภายใน 7 วัน และเกินกำหนด

- API GET /notifications ใช้ JWT และเลือกตามบัญชี หน่วยงานหลัก/รอง ทีม และผู้ร่วมทบทวน RCA ของผู้ใช้ แม้ Admin/RM ก็ไม่ดึงงานทั้งโรงพยาบาลมาเป็นแจ้งเตือนส่วนตัว
- ไม่แสดงเรื่องปิดเคส ไม่ใช่ความเสี่ยง งานทบทวนที่เสร็จแล้ว หรือการส่งต่อเพื่อ INFORM อย่างเดียว หน่วยงานต้นทาง=ปลายทางไม่ถือเป็นการส่งร่วมทบทวนหน่วยงานอื่น
- งาน RCA ใช้คิวที่ยังไม่เสร็จและ invitation ผู้ร่วมทบทวน ส่วนเดิมที่ยังไม่ได้เปิดจะเป็นยังไม่อ่านเมื่อเริ่มใช้ครั้งแรก ไม่ตีความว่าเพิ่งสร้างทั้งหมด
- วันครบกำหนดใช้ RCA due_at, Risk Register next_review_date, CAPA due_date/effectiveness_due_date และ active incident SLA ไม่คาดเดา deadline จากวันรายงาน
- Date-only ถึงกำหนดวันนี้ยังไม่ถือว่าเกินกำหนด ใช้วันปฏิทินประเทศไทย; SLA ใช้เวลาเต็ม
- เรื่องครบกำหนดหรือเกินกำหนดยังปรากฏแม้อ่านแล้ว จนสถานะงานเสร็จ ป้ายอ่านแล้วไม่เปลี่ยน workflow
- อ่านแล้วเก็บ key ใน browser แยก user.id (สูงสุด 2,000 key) ไม่ซิงก์ข้ามอุปกรณ์ ไม่เก็บเนื้อหาผู้ป่วย ไม่มีการเปลี่ยน schema
- โหลดใหม่ทุก 60 วินาทีและเมื่อกลับเข้าหน้า ขณะซ่อน tab จะไม่เรียก poll; เมื่อโหลดล้มเหลวแสดงข้อความ ไม่อ้างว่าไม่มีงาน
- แต่ละกลุ่มแสดงสูงสุด 50 เรื่องและแจ้งจำนวนทั้งหมดที่ตรงเงื่อนไข งาน RCA/ส่งร่วมทบทวนแสดงป้ายยังไม่อ่าน; เลขกระดิ่งรวมรายการยังไม่อ่านที่แสดงกับจำนวนงานถึง/เกินกำหนด
- หมายเลขเรื่องลิงก์ไป incident, RCA, CAPA หรือ Risk Register โดยตรง ไม่ส่ง narrative ใน payload กระดิ่ง
- ตรวจ preview ก่อนอนุญาต push/deploy เช่นเดิม
