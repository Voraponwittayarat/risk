# เมนูบัญชีและคู่มือ PDF

- มุมขวา: ปุ่มชื่อย่อเปิดโปรไฟล์ คู่มือ ตั้งค่าบัญชีของฉัน (เปลี่ยนรหัสผ่าน) และออกจากระบบ ปิดด้วย Escape / คลิกภายนอกได้ ไม่แสดงการอัปเดตคู่มือในเมนูบัญชี
- เมนูซ้าย: ปุ่ม Risk Register อยู่ด้านบน แสดง RR แม้แถบย่อ และเปิด /reports?view=register
- ลบปุ่มซ้ำ “โปรแกรม RCA (ภายใน)” ท้ายแถบซ้าย เข้า RCA ผ่านเมนู “ทบทวนและค้นหา RCA” ตามเดิม
- โปรไฟล์อ่านข้อมูลบัญชีและเปิดหน้าเปลี่ยนรหัสผ่านเดิมได้ การแก้ชื่อ/สิทธิ์ยังผ่านผู้ดูแล
- คู่มือ /manuals แยกผู้ปฏิบัติงานทั่วไปกับผู้บริหารความเสี่ยง ทุกบัญชีที่ล็อกอินอ่านได้ทั้งสองประเภท
- การอัปเดตคู่มือเข้าผ่านตั้งค่าระบบ /settings เท่านั้น ซึ่งลิงก์ไป /settings/manuals: Admin หรือ RM rmScope=hospital อัปโหลด PDF ชื่อคู่มือ และฉบับได้ ไม่เกิน 10 MB
- API ตรวจ JWT สิทธิ์ผู้เผยแพร่ ขนาดและลายเซ็น PDF ไฟล์ไม่เปิดเป็น public static
- เก็บไฟล์ภายใต้ UPLOAD_DIR/manuals พร้อม metadata ฉบับใหม่แสดงแทนโดยเก็บฉบับเก่าไว้ เผยแพร่ metadata เมื่อ PDF เขียนเสร็จเท่านั้น ไม่เปลี่ยน schema ฐานข้อมูล
- ต้องสำรอง uploads ด้วย --include-uploads ตามคู่มือ deploy เพื่อครอบคลุมไฟล์คู่มือด้วย
- preview ใช้ข้อมูลสมมติแยกจาก production ไม่มีการส่งไฟล์ขึ้น server จริง
- ผู้ใช้ตรวจ preview และอนุญาต push วันที่ 4 ตุลาคม 2569 ใช้ flow GitHub main → server poll ทุก 5 นาที → updater เดิม

ตรวจแล้ว: frontend/backend build ผ่าน; Jest 9 กรณีผ่าน ครอบคลุม JWT guard, สิทธิ์อัปโหลด, multipart upload/download, validation และการคงฉบับเก่าหลังรีสตาร์ต ตรวจลิงก์โปรไฟล์ หน้าตั้งค่าคู่มือ และ Escape ปิดเมนูใน preview แล้ว

ข้อจำกัด: ตรวจรูปแบบ PDF เบื้องต้น ไม่ใช่การสแกนมัลแวร์ ผู้เผยแพร่ควรใช้ไฟล์คู่มือที่ตรวจแล้วและไม่มีข้อมูลผู้ป่วย
